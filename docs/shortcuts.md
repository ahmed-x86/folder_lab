# اختصارات لوحة المفاتيح (Keyboard Shortcuts)

| الاختصار | الوظيفة |
|---|---|
| `Alt + Left` أو `Backspace` | الرجوع للخلف (Back) |
| `Alt + Right` | التقدم للأمام (Forward) |
| `Alt + Up` | الصعود للمجلد الأب (Up) |
| `F5` أو `Ctrl + R` | تحديث المجلد الحالي (Refresh) |
| `Ctrl + H` | إظهار / إخفاء الملفات المخفية |
| `Ctrl + Shift + N` | إنشاء مجلد جديد (New folder) |
| `Delete` | حذف الملف / المجلد المحدد |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` | نسخ، قص، ولصق |
| `Ctrl + 1` | التبديل إلى العرض الشبكي (Grid View) |
| `Ctrl + 2` | التبديل إلى عرض القائمة التفصيلية (Details View) |
| `Ctrl + D` أو `Alt + P` | إظهار / إخفاء لوحة التفاصيل الجانبية (Details Pane) |
| `Esc` | إلغاء التحديد |
| `Enter` | الدخول إلى المجلد أو البارتشن المحدد |
| `الأسهم` | التنقل السلس بين الملفات |
| `الأحرف` | الانتقال السريع والدائري لأول ملف/مجلد يبدأ بالحرف (عربي وإنجليزي) مع دعم استمرار الضغط. |
